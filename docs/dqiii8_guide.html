Overview

DQIII8 is an autonomous AI orchestration system running on a VPS (Ubuntu, SSH-only). It routes user queries through a multi-tier LLM pipeline with domain-specific knowledge enrichment. The primary UI is a Telegram bot.

Core Philosophy

Cheapest tier first. Local Ollama → free cloud (Groq) → paid Claude only when quality demands it. Every query gets domain-enriched knowledge chunks before reaching the LLM.

Installation

Fresh Install (new VPS)

# 1. Clone the repository
git clone https://github.com/senda-labs/DQIII8-premium.git /root/dqiii8
cd /root/dqiii8

# 2. Run installer
bash install.sh

# 3. Configure environment
cp config/.env.example .env
nano .env   # Add your API keys (see below)

# 4. Install Claude Code
npm install -g @anthropic-ai/claude-code
claude login

# 5. Initialize database
sqlite3 database/dqiii8.db < database/schema_v2.sql

# 6. Pull Ollama models
ollama pull bge-m3
ollama pull qwen2.5-coder:7b

# 7. Index knowledge base
for d in applied_sciences formal_sciences natural_sciences social_sciences humanities_arts; do
    python3 bin/agents/knowledge_indexer.py --domain "$d"
done

# 8. Start services
systemctl enable --now dqiii8-bot
systemctl enable --now ollama

# 9. Verify
python3 -m pytest tests/test_smoke.py -q

DQ Pipeline (8 Steps)

User prompt
    ↓
[1] domain_classifier.py     → Classify domain (keyword → embedding fallback)
    ↓
[2] subdomain_classifier.py  → Refine subdomain (keyword match, 0ms)
    ↓
[3] hierarchical_router.py   → Multi-level softmax routing (τ₁=0.25)
    ↓
[4] domain_agent_selector.py → Select specialist agent + system prompt
    ↓
[5] knowledge_enricher.py    → Hybrid search: vector + FTS5 + graph → RRF merge
    ↓
[6] confidence_gate.py       → Should enrich? (cosine ≥ 0.55, composite ≥ 0.30)
    ↓
[7] intent_amplifier.py      → Build enriched prompt (tier-specific formatting)
    ↓
[8] stream_response()        → Send to LLM, stream response
